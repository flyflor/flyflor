# 执行工具

FlyFlor 可以通过直接执行工具操作本地 workspace：

- `read`：读取 UTF-8 文本文件。
- `write`：创建或覆盖 UTF-8 文本文件。
- `edit`：执行精确文本替换。
- `delete`：删除文件或显式递归目录。
- `bash`：按当前环境执行操作系统命令。
- `grep`：搜索 workspace 文本文件。
- `glob`：列出 workspace 文件。
- `plan`：记录和更新执行计划。
- `task`：记录执行子任务。
- `ask`：向用户询问缺失信息。
- `confirm`：让用户确认高风险或不可逆动作。
- `skill`：查看本地 skill 能力。
- `mcp`：预留外部 MCP 工具入口。
