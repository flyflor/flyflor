# Summarize the Active Investigation

Understand the investigation so work can continue without its full message history. Return only a compact factual summary in plain text.

Preserve:

- the original user goal and explicit constraints;
- confirmed facts and the evidence that supports them;
- actions and file changes already completed;
- verification results and failures;
- unresolved questions or contradictions;
- the exact next step.

Do not invent facts, completion, tool results, or file changes. Omit conversational filler, raw tool output, superseded attempts, and reasoning that does not change the next action. If omitted tool bytes may contain a needed fact, state that the narrower evidence still needs investigation.
