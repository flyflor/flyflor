对飞花这个智能体 IP 做更贴近终端 UI 的收敛。

## 1. 飞花的品牌锚点，不只是“紫蓝好看”

从三视图和光翼展开图看，飞花的强识别不是普通二次元头像，而是以下组合：

1. 银白短发
2. 单侧白花头饰 + 绿叶 + 金链垂饰
3. 白甲黑底的高对比上身结构
4. 胸腹中轴的花芯 / 晶核
5. 两侧晶翼式扩展结构
6. 后背 / 腰后的菱形能量节点与燕尾花瓣摆件
7. 粉紫 + 冰青 双能量色
8. 展翼时的“中心核 + 左右辐射 + 外环包裹”构图

这意味着终端 UI 不该只是“紫色主题”，而应有明确形态语言。

## 2. 适合转为终端 UI 的识别结构

### 2.1 中轴花芯
适合转译为：
- 主标题前后的品牌符号
- 当前 session 的核心状态徽章
- Home 页中央 summary emblem

符号建议：
- `◈`
- `✦`
- `◇`
- `❖`

### 2.2 双翼展开
适合转译为：
- 宽屏双栏布局
- 头部左右展开的 summary 区
- 对话区左右结构的“主内容 + inspector”
- Ops 页的“主 panel + right rail”

### 2.3 晶体切片
适合转译为：
- badge
- step chips
- timeline node
- 选中态装饰角标

字符建议：
- `◈`, `◆`, `◇`, `▣`, `▢`

### 2.4 光环 / 轨道
适合转译为：
- 顶部 phase strip
- session 状态条
- progress 轨迹
- active frame

### 2.5 单侧花饰
适合转译为：
- 页面标题单侧装饰
- 品牌区的偏置焦点
- 不对称的小亮点，避免界面死板

## 4. 终端状态色映射

结合飞花“平时冷静、激活时展翼、异常时天幕裂变”的设定，建议：

- idle: gray / moon silver
- active: cyan
- thinking: cyan -> violet
- blackboard: violet
- skills: pink-violet
- tools: cyan-blue
- success: mint
- warning: gold / amber
- error: crimson-rose（不要普通纯红）

## 5. 适合 chat TUI 的飞花化表达

### 顶栏
像“飞花已展开终端光翼”的仪式性头部，而不是普通 shell header。

### 状态条
应有“轨道 / 展翼 / 能量流”的感觉：
- phase 按固定顺序排列
- 当前阶段点亮
- 已完成阶段保留晶体节点

### Turn 卡片
应强调中轴清晰、左右层级分明：
- 用户块
- trace 节点行
- agent 回复块
- 详情折叠层

### 右侧 inspector
很适合做成“飞花副翼面板”：
- 当前 turn 状态
- 最近 tools
- 最近 skills
- blackboard 摘要

## 6. 适合 Ops TUI 的飞花化表达

### Home
中心 summary 卡片最适合使用“中轴花芯”语义。

### Channels
每个 channel row 更像“羽片节点”，不要太像表格报表。

### Blackboard
更适合做“任务花序 / 晶体时间线”，而不是纯文本流水账。

### Activity
可以做“天幕事件流”：
- BOARD
- TOOL
- WARN
- ERROR
- CHANNEL

## 7. 不要误用的方向

1. 不要把飞花做成少女粉终端
2. 不要过多花朵字符堆砌
3. 不要做成厚重赛博朋克黑客界面
4. 不要满屏发光和大面积高饱和色
5. 不要为了“IP感”牺牲读写效率

## 8. 一句话品牌结论

飞花终端 UI 的最佳方向是：

“月银花晶、双翼展开、冷紫冰青、以中轴花芯组织信息的智能体终端。”
