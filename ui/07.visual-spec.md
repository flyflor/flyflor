# 视觉规范与 IP 转译

本设计参考了 Flyflor 智能体 IP 头像，其视觉关键词不是传统黑客风，而是：
- 银白基底
- 紫蓝霓虹能量
- 花晶混合结构
- 细线精工几何
- 环形光晕 / 轨道
- 柔性发光而非强硬荧光

## 1. 品牌气质定位

终端 UI 应表达：
- 高智
- 优雅
- 可信
- 灵动
- 精密
- 有一点神秘与仪式感

不应表达：
- 粗砺黑客风
- 军工终端风
- 过度赛博朋克噪音
- 暴力霓虹

## 2. 终端主配色建议

### 主色
- Mist Silver: `#EAEAF6`
- Orchid Violet: `#C78BFF`
- Neon Cyan: `#6FE7FF`

### 辅色
- Petal Pink: `#F3A6D6`
- Deep Iris: `#6E5BFF`
- Leaf Mint: `#8EDBB5`

### 背景层
- Void Navy: `#0B1020`
- Night Indigo: `#141A31`
- Panel Shade: `#1B223D`

## 3. 状态色建议

- idle: silver / gray
- thinking: cyan
- blackboard: violet
- tools: blue-cyan
- skills: pink-violet
- streaming: bright silver
- success: mint
- warning: amber（少量使用，避免跳戏）
- error: rose-red（偏紫红，不要纯消防红）

推荐终端语义：
- success = `green` 或接近 mint 的 ANSI 色
- error = `red`
- warning = `yellow`
- active = `cyan`
- brand = `magenta`
- neutral meta = `gray`

## 4. 形状语言

参考头像里的花晶、吊饰、环形结构，终端形状语言建议：

### 4.1 边框
- 以单线 / round border 为主
- 少量局部切角感，用字符间距和 badge 模拟，不强行画复杂斜线
- 重要卡片可用 `round`
- 次级卡片可用 `single`

### 4.2 角与节点
- 不走厚重方块风
- 用“细边 + 小节点”的感觉
- section 标题前可使用：
  - `◆`
  - `◇`
  - `◈`
  - `✦`

### 4.3 分割线
- 使用轻分隔线：`─`
- 强调分段时可在中间加入品牌节点：
  - `── ✦ ──`
  - `── ◇ ──`

### 4.4 徽章 / badge
- 推荐胶囊式文本徽章，而不是重块按钮
- 例如：
  - `[THINKING]`
  - `[BOARD]`
  - `[TOOL×2]`
  - `[DEGRADED]`
- 宽终端上可做双层 badge：状态 + 数量

### 4.5 图标风格
- 轻几何、轻符号
- 避免太多 emoji
- 推荐使用：
  - status: `● ○ ◆ ◇ ■ ▣`
  - flow: `→ ↗ ↘`
  - activity: `•`
  - highlight: `✦`

## 5. 终端可实现的视觉转译

这是最关键部分。

### 可直接转译的元素

1. 环形光晕 -> 顶栏状态轨道/phase strip
2. 晶体结构 -> 菱形 badge / 节点符号 / 多段 chips
3. 花系优雅感 -> 柔和紫粉青配色 + 精细标题装饰
4. 金属镶嵌感 -> 细边框 + 层级卡片 + 中央节点
5. 翼状展开 -> 宽屏双栏布局中的左右展开感

### 可用终端手法表达

1. 颜色层级
- 用冷白、紫、青建立品牌感

2. 节点式信息结构
- 让 section / step / event 像“晶体节点”一样串联

3. 仪式感头部
- 顶栏不只是标题，而像“agent activated” 的控制台冠冕

4. 轻发光错觉
- 用高亮文本 + 深底面板产生发光感
- 不用重度 ASCII 装饰

5. 轨道感
- phase bar / status strip 按线性轨道排列

## 6. 不适合直接搬到终端的元素

以下元素不建议直接照搬：

1. 大面积渐变
- 终端无法稳定还原

2. 半透明晶体层叠
- 会变成噪音

3. 复杂花朵图形
- 容易俗、也很难对齐

4. 发丝级细节
- 在终端中没有意义

5. 过多 emoji 宝石/花朵
- 不同终端显示不一致

6. 超细碎背景粒子
- 会破坏信息密度

## 7. 最终视觉转译结论

Flyflor 的 TUI 品牌语言应该是：
- 深夜蓝背景上的银白主信息
- 紫 / 青作为智能体能量色
- 细线边框、晶体节点、轻徽章
- 不走厚重机械风，而走“灵性科技控制台”
- 视觉精致但交互务实

一句话总结：

这是一个“月银花晶系智能体终端”，而不是传统黑客终端。
