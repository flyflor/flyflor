# Execution Tools

FlyFlor can operate the local workspace through direct execution tools:

- `read`: read UTF-8 text files.
- `write`: create or overwrite UTF-8 text files.
- `edit`: perform exact text replacements.
- `delete`: delete files or explicitly recursive directories.
- `bash`: execute operating-system commands adapted to the current environment.
- `grep`: search workspace text files.
- `glob`: list workspace files.
- `plan`: record and update execution plans.
- `task`: record execution subtasks.
- `ask`: ask the user for missing information.
- `confirm`: ask the user to confirm risky or irreversible actions.
- `skill`: inspect local skill capability.
- `mcp`: reserved gateway for external MCP tools.
