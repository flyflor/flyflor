# Flyflor Front

Flyflor 官网前端，使用 Bun + Nuxt 开发，支持中文和英文内容。

## Setup

```bash
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
bun run dev
```

## Checks

```bash
bun run check
bun run build
```

## Redlines

- 所有文件 4 空格缩进。
- Vue SFC 按 `<template>`、`<script setup lang="ts">`、`<style scoped>` 排列。
- 中英文内容同步维护。
